      Questions fréquentes

      Avant de lancer le scan

      Mes données sont-elles envoyées quelque part ?

      Non. Le calcul se fait dans votre navigateur et rien n'est transmis. Vous ne nous envoyez le résumé que si vous le décidez, et il ne contient que des nombres.

      Le script modifie-t-il ma plateforme ?

      Non. Il ne fait que des lectures : il se connecte, compte les objets par type, se déconnecte. Il n'exporte aucun nom de document, d'utilisateur ou de serveur, et le mot de passe n'est jamais enregistré.

      Quels droits faut-il ?

      Un compte qui voit tout le référentiel, en pratique un administrateur, et l'application « RESTful Web Services » autorisée pour ce compte dans la CMC. Avec un compte limité, les chiffres sont plus bas que la réalité.

      Le script n'arrive pas à se connecter

      Il affiche la cause probable. Le plus souvent, l'API REST n'écoute pas sur le port 6405 : l'adresse exacte figure dans la CMC, rubrique Applications, RESTful Web Service, Propriétés. Vous pouvez aussi lancer le script depuis le serveur BusinessObjects lui-même. Si votre poste bloque le collage, enregistrez le script dans un fichier trivoie.ps1 et lancez powershell -ExecutionPolicy Bypass -File .\trivoie.ps1.

      Les chiffres sont-ils fiables ?

      Le script compte chaque type avec deux méthodes, COUNT(SI_ID) et une liste TOP N qui lève la limite de 1 000 lignes appliquée par défaut, et vérifie qu'elles concordent. Si ce n'est pas le cas, la page vous le signale.

      Pourquoi agir avant le 31 décembre ?

      Le diagnostic prend 10 jours ouvrés. Lancé à temps, il vous donne un plan chiffré avant l'échéance, pour décider en connaissance de cause plutôt que subir la maintenance spécifique client. Après, il sert à limiter la durée d'exposition en 2027.

      Quelle voie est la bonne pour moi ?

      Le scan mesure votre exposition et les chantiers à traiter. Le choix de la voie dépend aussi de vos usages, de vos contrats et de votre budget : c'est l'objet du diagnostic, qui chiffre les trois voies pour votre plateforme.
